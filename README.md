# 💳 Razorpay Clone

A modern and responsive **Razorpay-inspired payment platform landing page** built to practice frontend development and modern UI design.

The project focuses on creating a clean fintech-style interface using **HTML, Tailwind CSS, JavaScript, and Vite**.

## 🌐 Live Website

🔗 https://amitgangwar8144-design.github.io/Razorpay-Clone/

## 📌 Project Overview

This project is a frontend recreation inspired by the design and layout of Razorpay.

It includes multiple sections commonly found on a modern payment platform, with responsive layouts, interactive hover effects, SVG graphics, and a clean user interface.

## ✨ Features

- Responsive navigation bar
- Modern fintech-style UI
- Hero section with CTA buttons
- Payment solution sections
- Business banking section
- Capital & credit section
- Payouts section
- Company/logo showcase
- Interactive hover effects
- SVG-based UI elements
- Responsive layout for mobile, tablet and desktop
- Clean and reusable Tailwind CSS utility classes
